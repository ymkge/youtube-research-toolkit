# YouTube動画広告活用 & バズ動画ブースト戦略ガイドライン

## 1. 動画広告活用の本質と評価メカニズム
* **目的は「再生数の購入」ではなく「アルゴリズムの初速ブースト」**:
  単に広告を出稿してもアルゴリズムのおすすめ表示は増えない。自然流入で高いクリック率（CTR）や視聴維持率を記録し始めた「バズの兆候がある動画」に少額広告を投下し、アルゴリズムのおすすめ・関連動画への波及を加速させることが真の目的である。
* **アルゴリズムが評価する「獲得アクション（Earned Actions）」**:
  YouTubeは有料再生数そのものを評価するのではなく、広告で流入したユーザーが起こす「他動画の自発的視聴（Earned Views）」「高評価」「チャンネル登録」「プレイリスト保存」などの二次的オーガニック行動を強く評価する。

## 2. 採用すべき広告フォーマットと事前準備
* **インフィード動画広告（またはYouTube Studioのプロモーション）のみ採用**:
  * サムネイルをクリックして能動的に視聴する形式のみが有効。
  * **スキップ可能なインストリーム広告は厳禁**: 強制割り込み型は視聴維持率を破壊し、特にBGM・作業用ジャンルでは致命傷となる。
* **必須事前準備**:
  1. **Google広告とYouTubeチャンネルのリンク**: Earned Metrics（獲得視聴数・獲得登録者数）の計測やリマーケティングに不可欠。
  2. **ミッドロール広告の一時停止**: 広告投下中の動画は、作業集中の妨害と即離脱を防ぐためミッドロール広告をオフ（または30分以降）に設定する。
  3. **回遊導線の整備**: 終了画面に代表作や作業用プレイリストを設定し、固定コメント最上部にトラックリストと再生リストURLを配置する。

## 3. コスト相場と主要KPI（インフィード広告）
* **日本国内向け**:
  * 視聴単価（CPV）: **3円 〜 10円 / 1再生**
  * 登録獲得単価（CPA）: **150円 〜 500円 / 1登録**
  * 広告CTR: **2.0% 〜 4.5%**
* **英語圏・グローバルTier 1（米国・英国等）**:
  * 視聴単価（CPV）: **4円 〜 12円 / 1再生**
  * 登録獲得単価（CPA）: **200円 〜 800円 / 1登録**
* **超低単価国（インド・東南アジア等）の注意点**:
  * 登録単価は数円〜20円と格安だが、次回以降の動画が見られず、チャンネルのRPM（収益性）を破壊するため、全世界一括配信は避け、高RPM国へホワイトリスト配信する。

## 4. 運用フロー・撤退基準・エグジット基準
1. **発動トリガー条件**:
   * 公開後24〜72時間で、オーガニックCTRが **7%〜10%以上**。
   * 平均視聴維持時間がチャンネル平均以上（BGMなら15〜20分以上）。
   * トラフィックソースの「ブラウジング機能」または「関連動画」が自然に立ち上がり始めていること。
2. **小額テスト（Day 1〜3）**:
   * 日予算 1,000円〜2,000円で3日間運用。
   * 見出し・説明文には「作業/勉強用途」「音の質感（Lo-Fi等）」を明記し、ミスマッチクリックを防止。
3. **撤退基準（損切りライン）**:
   * 広告CTRが 1.5%未満（消化1,000円時点）。
   * 登録単価（CPA）が 1,000円超、または他動画への回遊が皆無（消化3,000円時点）。
   * オーガニック流入（ブラウジング機能）に72時間以内に連動・拡大の兆候が見られない場合。
   * 上記のいずれかに該当した場合は**即時停止**し、次作制作へ切り替える。
4. **本投下とエグジット（終了基準）**:
   * 反応良好なら日予算 3,000円〜5,000円へ拡大。
   * トラフィックソースの80%以上がオーガニック（ブラウジング＋関連動画）になり、自然流入が自走し始めたら広告予算を段階的に減らし、停止する。

## 5. 効果測定とアナリティクス確認
* **YouTube Studio「詳細モード」＞「トラフィックソース」**:
  * 「YouTube 広告」の推移と同時に、「ブラウジング機能」「関連動画」が右肩上がりに連動して伸びているかを監視。
* **Google広告「獲得項目（Earned Metrics）」**:
  * 広告経由の直接再生だけでなく、「獲得した視聴回数（Earned Views）」が広告再生数の20%以上発生しているかを確認する。
